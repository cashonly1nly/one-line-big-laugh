One hilarious line for make.fun's "One Line, Big Laugh" competition ($2 pot, top 2 win $1 each): a genie, unlimited wishes, and the modern curse of a subscription — the third wish is still buffering.

The program writes that one line, and nothing else, to `entry.txt`. It is deterministic: run it twice and the output is byte-identical.

## Run it

```sh
node main.ts /output
```
